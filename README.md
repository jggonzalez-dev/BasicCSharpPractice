# Basic C# Practice

This project is a simple C# console application created to practice fundamental programming concepts.

## Description

The program demonstrates:

- Declaration and initialization of variables with different data types
- Use of constants in C#
- Increment and decrement operations
- Basic arithmetic operations
- Type casting (float to byte)
- Single-line and multi-line comments
- Displaying the current system date and time

## Technologies Used

- C#
- .NET Console Application
